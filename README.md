# Stolowka-Studencka



Kontekst projektu

Projekt dotyczy systemu informatycznego wspierającego funkcjonowanie stołówki studenckiej. System umożliwia klientom przeglądanie aktualnego menu, sprawdzanie dostępności posiłków, składanie zamówień oraz dokonywanie płatności online.

Głównym celem systemu jest usprawnienie procesu zamawiania i wydawania posiłków. Klient może złożyć zamówienie przed przyjściem do stołówki i odebrać je po przygotowaniu. Pozwala to ograniczyć kolejki oraz usprawnić organizację pracy stołówki.

Po złożeniu i opłaceniu zamówienia trafia ono do obsługi stołówki. Pracownik realizuje zamówienie i aktualizuje jego status. Klient może na bieżąco sprawdzić, czy zamówienie jest już gotowe do odbioru.

System uwzględnia również sytuacje wyjątkowe, takie jak brak dostępności wybranego dania lub niepowodzenie płatności.



Lista aktorów

Klient

Osoba korzystająca z oferty stołówki, np. student lub pracownik uczelni.

Klient może:

•	przeglądać aktualne menu,

•	sprawdzać dostępność dań,

•	składać zamówienia,

•	dokonywać płatności,

•	sprawdzać status zamówienia,

•	odbierać gotowe zamówienie.

Pracownik stołówki

Osoba odpowiedzialna za obsługę i realizację zamówień.

Pracownik może:

•	przeglądać złożone zamówienia,

•	przyjmować zamówienia do realizacji,

•	przygotowywać zamówienia,

•	aktualizować status zamówienia,

•	oznaczać zamówienie jako gotowe lub wydane,

•	aktualizować dostępność dań.

Administrator

Osoba odpowiedzialna za zarządzanie systemem.

Administrator może:

•	zarządzać menu,

•	dodawać i edytować dania,

•	zmieniać ceny,

•	zarządzać kontami użytkowników,

•	konfigurować podstawowe parametry systemu.

System płatności

Zewnętrzny system odpowiedzialny za przeprowadzenie płatności online. Odbiera żądanie płatności i przekazuje informację o powodzeniu lub niepowodzeniu transakcji.
