# Spis technologiczny projektu

## 1. Backend

### C#
Język programowania wykorzystywany do tworzenia logiki aplikacji, obsługi operacji oraz komunikacji z bazą danych. Został wybrany ze względu na czytelną składnię, dobrą współpracę z technologiami firmy Microsoft oraz dla wygody naszej grupy.

### ASP.NET Core
Platforma wykorzystywana do tworzenia aplikacji internetowych. Umożliwia obsługę żądań użytkowników, realizację logiki aplikacji oraz komunikację pomiędzy frontendem a bazą danych. Współpracuje z językiem C#.

## 2. Frontend

### HTML
Język znaczników służący do tworzenia struktury stron internetowych. Umożliwia definiowanie elementów takich jak nagłówki, formularze, przyciski, tabele i inne elementy interfejsu użytkownika.

### CSS
Język arkuszy stylów odpowiedzialny za wygląd stron internetowych. Umożliwia określanie kolorystyki, czcionek, rozmieszczenia elementów oraz dostosowanie wyglądu aplikacji do różnych urządzeń.

## 3. Baza danych

### Microsoft SQL Server
Relacyjny system zarządzania bazą danych, wykorzystywany do przechowywania i organizowania danych aplikacji. Umożliwia tworzenie relacji między tabelami oraz wykonywanie zapytań SQL.

### SQL Server Management Studio (SSMS)
Narzędzie służące do zarządzania bazą danych Microsoft SQL Server. Umożliwia tworzenie i edytowanie tabel, zarządzanie strukturą bazy danych oraz wykonywanie zapytań SQL.

## 4. System kontroli wersji i współpracy

### Git
Rozproszony system kontroli wersji umożliwiający śledzenie zmian w kodzie źródłowym, tworzenie branchy oraz równoczesną pracę kilku osób nad jednym projektem.

### GitHub
Platforma internetowa służąca do przechowywania repozytorium projektu, zarządzania kodem źródłowym oraz współpracy zespołowej. Umożliwia korzystanie z Pull Requestów i przeglądanie zmian wprowadzanych przez członków zespołu. Jest też wymagany do projektu.
